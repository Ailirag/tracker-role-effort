# Трудозатраты по ролям

Плагин показывает плановые и фактические трудозатраты по задачам в разрезе ролей:
разработчик, аналитик, тестировщик и любые другие роли, принятые в вашей команде.
Соответствие полей задаётся отдельно для каждой очереди, поэтому плагин работает
с той схемой полей, которая уже используется в вашей организации.

## Возможности

- Разбивка трудозатрат по ролям на карточке задачи: план, факт, отклонение и
  список сотрудников, которые списывали время.
- Сводка по выборке задач на отдельной вкладке очереди: суммарный план и факт по
  каждой роли за нужный период, спринт или направление.
- Настройка соответствия полей для каждой очереди: поле с оценкой в часах и поля,
  по которым определяется исполнитель роли.
- Отдельная строка для трудозатрат, которые не удалось отнести ни к одной роли,
  чтобы неполные данные оставались заметными.
- Настраиваемый перевод рабочих дней и недель в часы.

## Кому подходит

- Руководителям групп и менеджерам проектов — чтобы видеть, как распределяется
  фактическая нагрузка между ролями и где расходятся план и факт.
- Аналитикам и владельцам процессов — чтобы оценивать точность планирования по
  каждой роли, а не только по задаче целиком.
- Командам, которые ведут ролевые оценки в отдельных полях задачи и списывают
  время через журнал работ.

## Как начать

1. Откройте очередь и перейдите на вкладку «Трудозатраты по ролям».
2. В разделе «Настройки» добавьте роли: укажите название, поле с оценкой в часах
   и одно или несколько полей, по которым определяется исполнитель роли.
   Поля выбираются из списка полей этой очереди.
3. При необходимости измените количество часов в рабочем дне и рабочей неделе —
   эти значения используются для перевода длительностей из журнала работ.
4. Сохраните настройки. После этого разбивка появится на карточках задач очереди,
   а на вкладке «Сводка» можно посчитать итоги по произвольной выборке задач.

## Как считаются данные

План берётся из числового поля роли, указанного в настройках. Факт собирается из
журнала работ: запись относится к роли, если её автор указан в поле исполнителя
этой роли. Записи, которые не удалось сопоставить ни с одной ролью, показываются
отдельной строкой и не смешиваются с итогами по ролям.

Отклонение показывается как отношение факта к плану. Значения в пределах
плюс-минус двадцати процентов считаются попаданием в оценку.

## Ограничения

Сводка по очереди загружает задачи по одной, так как пользовательские поля ролей
не возвращаются массовым поиском. Поэтому объём выборки ограничен, а при
достижении лимита выводится предупреждение о том, что итоги посчитаны не по всем
найденным задачам.

Плагин читает данные и не изменяет задачи, поля и записи журнала работ.

## Права доступа

Плагин запрашивает доступ на чтение задач, очередей, полей, журнала работ и
данных пользователей. Права на запись не запрашиваются. Данные отображаются в
объёме прав текущего пользователя.
